## 🗺️ Roadmap для поочередной реализации

**Для модульной реализации используй**: [roadmap/00_README.md](roadmap/00_README.md)

Roadmap разбит на **14 модулей** для поочередной реализации. Каждый модуль можно реализовывать отдельно.

**Пример промпта**:
```
Реализуй модуль 01_BACKEND_FOUNDATION из roadmap банковского симулятора.
```
