## 🔴 Реальные проблемы

### 1. Нет системы итоговой оценки (`EvaluationService`)

**Доки описывают** (`04_FORMULAS.md`, `05_IMPLEMENTATION_GUIDE.md`):
- Весовая оценка: Корректность решения (40%) + Качество обслуживания (30%) + Соблюдение регламентов (30%)
- Отдельный `EvaluationService.php` для расчёта финального балла

**В коде**: только `add_score_points` в диалоговых действиях — простое суммирование баллов без категоризации.

**Почему проблема**: Без итоговой оценки невозможно дать студенту обратную связь: «ты хорошо собрал данные, но плохо объяснил условия». Сейчас все баллы в одной куче.

**Как исправить**:
- Создать `app/Services/Simulators/BankSimulator/EvaluationService.php`
- В `add_score_points` добавить поле `category`: `correctness`, `service_quality`, `compliance`
- При завершении сессии — `EvaluationService` подсчитывает итог по категориям с весами
- На фронте — показать разбивку по категориям (радар-чарт или прогресс-бары)

---

### 2. Мало шаблонов клиентов

**Доки описывают** (`03_CURRENT_STATE.md`): student, family, business, pensioner

**В конфиге**: только `student` и `entrepreneur`

**Почему проблема**: Разные типы клиентов тренируют разные навыки. Семья с ипотекой — совсем другой диалог, чем студент с кредиткой. Два шаблона — мало для учебного разнообразия.

**Как исправить**:
- Добавить в `config/simulators/bank_simulator.php` секцию `client_templates`:
  - `family` (30–45 лет, доход 100–200к, КИ good/excellent, вклад вероятен)
  - `pensioner` (55–70 лет, доход 25–50к, КИ excellent, вклад вероятен)
- Добавить `model_path` для каждого нового типа (или использовать существующие модели)

---

### 3. Диалоги «вклад» и «консультация» не реализованы

**Доки описывают** (`02_TASK.md`): три типа диалога — кредитная карта, вклад, консультация

**В коде**: кредитная карта, ипотека, потребительский кредит

**Почему проблема**: Сценарий **вклада** — принципиально другой продукт (не кредит). Он тренирует другие навыки: расчёт доходности, объяснение капитализации, сравнение условий. Без него симулятор покрывает только кредитную сторону банка. Три текущих сценария по сути — вариации одного и того же (кредитование).

**Как исправить**:
- Создать `config/simulators/dialogues/deposit.php` — сценарий «клиент хочет открыть вклад»
  - Стадии: приветствие → цель (накопление/сохранение) → сумма → срок → объяснение капитализации → расчёт → оформление
  - Использовать `calculate_deposit` action вместо `calculate_credit`
- Опционально: `consultation.php` — клиент не знает, что ему нужно (тренирует навык выявления потребности)
- Добавить `'deposit'` и `'consultation'` в `DialogueService::AVAILABLE_DIALOGUE_TYPES`
