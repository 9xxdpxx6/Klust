# 🗺️ Roadmap: Банковский симулятор

## Структура roadmap

Roadmap разбит на **модули** для поочередной реализации. Каждый модуль можно реализовывать отдельно.

## 🚀 Как использовать roadmap

### Для реализации модуля:

1. **Открой соответствующий файл** (например, `01_BACKEND_FOUNDATION.md`)
2. **Прочитай описание модуля**:
   - Что делает
   - Зависимости
   - Файлы для создания/изменения
   - Критерии готовности
3. **Используй чеклист** для проверки выполнения
4. **Переходи к следующему модулю** после завершения

### Пример промпта для реализации модуля:

```
Реализуй модуль 01_BACKEND_FOUNDATION из roadmap банковского симулятора.
```

Или более детально:

```
Реализуй модуль 04_3D_SCENE_BASIC:
- Создай базовую 3D сцену с TresJS
- Добавь стол и монитор
- Настрой камеру first-person view
- Добавь освещение
```
