# 🎯 Задача для разработчиков

## Цель

Разработать **стратегию и прототип** банковского симулятора "Финансовый Консультант". 

**Важно**: Это НЕ полноценная реализация, а **архитектурное решение и proof-of-concept**.

Создать документ `BANK_SIMULATOR_ARCHITECTURE.md` с описанием:

#### 1.1. Структура данных
- Какие данные хранить в `SimulatorSession.state` (JSON)
- Структура клиента (профиль, финансы, история)
- Структура диалога (сообщения, выборы, этапы)
- Структура расчетов (скоринг, калькуляторы)

#### 1.2. Компонентная архитектура Vue
- Список Vue компонентов и их назначение
- Схема взаимодействия компонентов
- State management (локальный state vs Pinia)

#### 1.3. Backend архитектура
- Какие сервисы создать (например, `BankSimulatorService`, `ScoringService`, `ClientGeneratorService`)
- Какие методы нужны в контроллерах
- Какие миграции/модели добавить (если нужно)

#### 1.4. Алгоритмы и формулы
- Детальное описание формулы скоринга (с примерами)
- Логика кредитного калькулятора
- Логика калькулятора вкладов
- Система оценки действий пользователя

### 2. Прототип интерфейса (статичный Vue)

Создать **один статичный компонент** `BankSimulatorPrototype.vue` который показывает:

#### 2.1. Игровая 3D сцена (low-poly стиль)
- **First-person view** из офисного кресла консультанта
- 3D стол перед пользователем
- 3D монитор на столе с банковским интерфейсом
- 3D/2D клиент сидящий напротив (верхняя часть видна)
- Предметы на столе (телефон, документы) - интерактивные

**Подробности**: См. [06_VISUALIZATION.md](06_VISUALIZATION.md)

#### 2.2. Макет интерфейса
- **На мониторе** (внутри 3D сцены):
  - Интерфейс банковской системы
  - Диалог с клиентом
  - Анкета клиента
  - Результаты скоринга
- **UI панели** (поверх сцены):
  - Калькуляторы (кредит, вклад)
  - Индикаторы прогресса
  - Кнопки действий

#### 2.3. Интерактивность (минимальная)
- Клики по объектам на столе (телефон, документы)
- Кнопки выбора реплик (в диалоге на мониторе)
- Заполнение анкеты клиента (формы)
- Калькулятор кредита (ввод суммы, срока → расчет платежа)
- Визуализация результата скоринга (процент одобрения, индикатор риска)

#### 2.4. Визуальный стиль
- **Low-poly / Stylized** дизайн (как в job simulator)
- Простые геометрические формы
- Цветовая схема: синий (#1E40AF), коричневый (#8B4513), бежевый (#F5DEB3)
- Простые анимации (кивание клиента при диалоге)

**Важно**: Это НЕ рабочий симулятор, а **визуальный прототип** для демонстрации концепции. Визуал должен быть **околоигровым** (3D/low-poly), а не визуальной новеллой.
