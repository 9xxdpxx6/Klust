## 🔧 SQL-запросы для верификации

```sql
-- Заявки на ваш кейс
SELECT ca.id, ca.leader_id, u.name, s.name as status, ca.partner_comment, ca.rejection_reason, ca.reviewed_at
FROM case_applications ca
JOIN users u ON ca.leader_id = u.id
JOIN application_statuses s ON ca.status_id = s.id
WHERE ca.case_id = {case_A1_id};

-- Участники команды
SELECT ctm.*, u.name
FROM case_team_members ctm
JOIN users u ON ctm.user_id = u.id
WHERE ctm.application_id = {application_id};

-- История статусов
SELECT cash.*, 
  old_s.name as old_status, new_s.name as new_status
FROM case_application_status_histories cash
LEFT JOIN application_statuses old_s ON cash.old_status_id = old_s.id
LEFT JOIN application_statuses new_s ON cash.new_status_id = new_s.id
WHERE cash.case_application_id = {application_id}
ORDER BY cash.changed_at DESC;
```
