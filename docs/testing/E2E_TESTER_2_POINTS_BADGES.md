## 🔧 SQL-запросы для верификации

```sql
-- Начальные / текущие баллы студентов
SELECT u.id, u.name, sp.total_points
FROM users u
JOIN student_profiles sp ON u.id = sp.user_id
WHERE u.id IN ({student1_id}, {student2_id}, {student3_id});

-- Сессии симулятора
SELECT ss.id, ss.user_id, ss.simulator_id, ss.score, ss.time_spent, 
       ss.started_at, ss.completed_at, sim.name
FROM simulator_sessions ss
JOIN simulators sim ON ss.simulator_id = sim.id
WHERE ss.user_id = {student_id}
ORDER BY ss.created_at DESC;

-- ProgressLog (начисления баллов)
SELECT pl.id, pl.user_id, pl.action, pl.points_earned, pl.created_at,
       s.name as skill_name
FROM progress_logs pl
JOIN skills s ON pl.loggable_id = s.id AND pl.loggable_type = 'App\\Models\\Skill'
WHERE pl.user_id = {student_id}
ORDER BY pl.created_at DESC;

-- Навыки студента (уровни и очки)
SELECT us.user_id, s.name, us.level, us.points_earned
FROM user_skills us
JOIN skills s ON us.skill_id = s.id
WHERE us.user_id = {student_id};

-- Бейджи студента
SELECT b.name, b.required_points, ub.level, ub.earned_at
FROM user_badges ub
JOIN badges b ON ub.badge_id = b.id
WHERE ub.user_id = {student_id};

-- Статус кейса (для проверки автозакрытия)
SELECT id, title, status, deadline FROM cases WHERE id IN ({B1_id}, {B2_id});
```

## 📌 Формула начисления баллов (справочник)

| Score симулятора | Начисляемые баллы    | Описание              |
|------------------|----------------------|-----------------------|
| null             | 10                   | Значение по умолчанию |
| < 50             | max(10, score × 0.5) | Минимум 10 очков      |
| 50–74            | score                | Стандартные очки       |
| 75–89            | score + 10           | Бонус за хорошую работу |
| ≥ 90             | score + 20           | Бонус за отличную работу |
